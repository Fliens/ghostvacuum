# Dashboard icons

Selected interface icons by Alexander Kahlkopf / iconmonstr.
Use is governed by https://iconmonstr.com/license/ (retrieved 2026-10-11).
Icons are incorporated into the dashboard design, not supplied as a standalone icon collection. The GhostVacuum logo is independent.

The official PNG previews were vectorized locally with VTracer because the original SVG download links returned expired-key errors. The embedded CSS masks contain only vector paths, without raster images or SVG filters. No browser requests to iconmonstr are made.
